### d0ublecl1ck · DeepSeek Harness 插件作者

Python · TypeScript · Go · Rust —— 做 AI coding agent 的工具链、插件与自动化。

**DSH（DeepSeek Harness）Web 插件**

| 插件 | 做什么 |
| --- | --- |
| [dsh-unarchived-watch](https://github.com/d0ublecl1ck/dsh-unarchived-watch) | 未归档会话积压超过阈值时，侧栏亮警告 + 按工作区分组的只读看板 |
| [dsh-hide-empty-workspace](https://github.com/d0ublecl1ck/dsh-hide-empty-workspace) | 最后一个未归档会话被归档的瞬间自动隐藏该工作区行（纯展示，不写任何数据） |
| [dsh-search-enhance](https://github.com/d0ublecl1ck/dsh-search-enhance) | 「新建会话」的工作区下拉支持拼音首字母、全拼与子串搜索 |
| [dsh-skill-dollar](https://github.com/d0ublecl1ck/dsh-skill-dollar) | 用 `$name` 手势调用 skill，与 `/` 命令不冲突，带补全 |
| [dsh-external-link](https://github.com/d0ublecl1ck/dsh-external-link) | 让 GUI 里的 http / mailto / tel 链接走系统默认程序打开 |
| [dsh-csdn-theme](https://github.com/d0ublecl1ck/dsh-csdn-theme) | CSDN 博文的配色与正文排版主题 |

六个插件都是 MIT，安装方式见各仓库 README。
